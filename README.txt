Mentoobeing MVP

Files:
- index.html: complete self-contained website
- robots.txt
- sitemap.xml

Logo note:
The master prompt references the final approved logo, but the uploaded source in this build did not include the logo image. The UI therefore isolates the logo mark in .logo/.big-logo so the approved asset can replace it without changing the layout.

Run locally:
1. Open index.html directly in a modern browser, or
2. python -m http.server 8000 from this folder and visit http://localhost:8000

The site is static. No backend or API keys are required for the MVP interactions.
